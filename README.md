# Flashcard Quiz App

A simple Flashcard Quiz App developed as part of my CodeAlpha Internship.

## Features

- View flashcards
- Show and hide answers
- Next and Previous navigation
- Add flashcards
- Edit flashcards
- Delete flashcards
- Save flashcards using Local Storage

## Technologies Used

- HTML
- CSS
- JavaScript

## Internship

Developed as part of the CodeAlpha App Development Internship.
